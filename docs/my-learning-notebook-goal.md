# マイ学習ノート改修ゴール

## ゴール

旧「マイ単語」のID・保存配列・学習履歴を維持したまま、次の8分野を一つの自分専用ノート兼問題集として扱えるようにする。

| 分野 | 正本データ | 対象件数 |
| --- | --- | ---: |
| 英単語 | `ALL_WORDS` | 8,169 |
| 英熟語・構文 | `PHRASES` | 1,500 |
| 英文法 | `GRAMMAR` | 3,140 |
| リスニング | `LISTENING_ITEMS` | 160 |
| 語源 | `ETYMOLOGY_PACKS` | 2,672 |
| 古典単語 | `KOTEN_WORDS` | 300 |
| 古典文法 | `KOTEN_GRAMMAR` | 74 |
| 古典常識 | `KOTEN_CULTURE` | 56 |
| 合計 | 8分野の全項目 | 16,071 |

対象件数は改修時点の正本データ全件であり、抜粋や例示だけを対象にしない。教材追加後は、正本データと統合カタログの一対一対応を自動監査する。

## 機能要件

1. 8分野を同じ画面で切り替え、全分野横断または分野別に、見出し・意味・本文・分類から検索できる。
2. 各項目を保存・解除でき、最大2,000字の個別メモと最大12個のタグを編集できる。
3. 最大40冊の自作問題集を作り、名称・説明・最大500項目の内容・順番を編集できる。1冊には複数分野を混在できる。
4. 問題集または個別項目から、各分野の既存カード・テストへ接続する。1回の学習は分野別の適切な上限内で、復習期限、未学習、定着段階を優先する。
5. SRSの正誤、定着段階、復習期限、最近の学習、問題集の利用履歴を統合表示する。
6. 端末保存、`EQ1-`進捗コード、クラウド保存・復元、リセット、個別消去の全経路でノートを扱う。
7. 旧 `myList`、`kotenWordList`、`kotenGrammarList`、`kotenCultureList` は残し、旧画面からの保存・解除と統合ノートを双方向同期する。
8. 320×568と390×844で、主要操作、検索、ノート編集、問題集編集、履歴確認に横スクロールや操作不能がない。

## 影響する入口・画面

- 主画面: `myList`（マイ学習ノート）
- 補助索引: `myLearning`
- 直接保存: `vocabStudy` / `vocabQuiz` / `wordDetail`、`phraseStudy` / `phraseQuiz`、`grammarQuiz`、`listeningQuiz`、古典単語・文法・常識の各学習/クイズ。語源からの学習も専用画面ではなく `vocabStudy` を使う。
- 学習記録・復元確認: `progress`
- 共通入口: 下部「マイ学習」、メニュー「マイ学習ノート」

## 互換性契約

- 教材ID、既存SRS、旧保存配列、辞書履歴、英作文の `myGrammarList`、進捗コード接頭辞、localStorageキーを変更しない。
- 教材本文をノート状態へ複製せず、`domain:itemId` の安定参照だけを保存する。語源のようにID内にコロンがある場合も、最初のコロンだけを分野区切りとして復元する。
- 新しい永続項目は `PERSISTED_PROGRESS_FIELDS` / `selectProgressState()` の一元契約を通す。
- 新項目を持たない旧端末データ・旧進捗コードは空の統合ノートとして読み込める。新項目を持たない古いクラウド保存で、現在端末の新しいノートを消さない。

## 完了判定

次をすべて満たした場合だけゴール完了とする。

- `npm run audit:notebook` が8分野・全16,071件、安定参照、保存形式、問題集、学習経路、永続化経路をエラー0件で監査する。
- 統合ノートの対象テストが、旧リスト互換、メモ・タグ上限、問題集編集、SRS履歴、端末/コード/クラウド往復を通過する。
- `npm test`、`npm run check`、`npm run build`、`git diff --check`、`npm run check:deployment` が通過する。
- 実ブラウザで保存、再読込、新規タブ復元、問題集作成/編集、各8分野の学習起動、進捗反映を確認する。
- 390×844と320×568の両方で横方向の欠落がなく、コンソールエラーがない。
