# マイ学習ノート改修ゴール

## ゴール

旧「マイ単語」と古典・漢文の登録リストの内容・学習履歴を引き継ぎ、英語・古典・漢文の次の14教材を、一つの自分専用ノート兼単語帳として扱えるようにする。

| 教材 | 正本データ | 対象件数 |
| --- | --- | ---: |
| 英単語 | `ALL_WORDS` | 8,851 |
| 英熟語・構文 | `PHRASES` | 2,104 |
| 英文法 | `GRAMMAR_PRACTICE` | 3,555 |
| リスニング | `LISTENING_ITEMS` | 160 |
| ディクテーション | `DICTATION_ITEMS` | 140 |
| 語源 | `ETYMOLOGY_PACKS` | 339 |
| 古典単語 | `KOTEN_WORDS` | 300 |
| 古典文法 | `KOTEN_GRAMMAR` | 74 |
| 古典常識 | `KOTEN_CULTURE` | 56 |
| 短文解釈 | `KOTEN_INTERPRETATIONS` | 36 |
| 漢語 | `KANBUN_VOCAB` | 120 |
| 漢文法 | `KANBUN_GRAMMAR` | 87 |
| 漢文常識 | `KANBUN_CULTURE` | 95 |
| 返り点 | `KANBUN_KUNDOKU_EXERCISES` | 40 |
| 合計 | 14教材の全項目 | 15,957 |

対象件数は2026-09-12時点の正本データ全件であり、抜粋や例示だけを対象にしない。教材追加後は、正本データと統合カタログの一対一対応を自動監査する。

## 機能要件

1. 14教材を同じ画面で切り替え、全教材横断または教材別に、見出し・意味・本文・分類から検索できる。
2. 各項目を保存・解除でき、最大2,000字の個別メモと最大12個のタグを編集できる。
3. 最大40冊の単語帳を作り、名称・説明・最大500項目の内容・順番を編集できる。1冊には複数の教材を混在できる。
4. 単語帳または個別項目から、各教材の既存カード・テストへ接続する。行き先は `src/lib/wordBookLaunch.js` の1か所で決め、単語画面・各コンテンツ・マイ学習ノートが同じものを使う。1回の学習は教材別の適切な上限内で、復習期限、未学習、定着段階を優先する。
5. SRSの正誤、定着段階、復習期限、最近の学習、単語帳の利用履歴を統合表示する。
6. 端末保存、`EQ1-`進捗コード、クラウド保存・復元、リセット、個別消去の全経路でノートを扱う。
7. 英単語の旧 `myList`（マイ単語）と、古典・漢文の旧登録リスト（`kotenWordList`・`kotenGrammarList`・`kotenCultureList`・`kanbunVocabList`・`kanbunGrammarList`・`kanbunCultureList`）は、読み込むときに単語帳（「マイ単語」「古典の登録リスト」「漢文の登録リスト」）とノートの保存へ移し、以後はほかの単語帳と同じ `learningNotebook.sets` の1冊として扱う。登録リストの画面・操作は置かない（2026-09-12）。
8. 暗記・テストのカードや一覧の保存ボタンは、どの教材も「単語帳」（入れる単語帳を選ぶ窓）にする。教材をまたいでまとめて入れる項目（短文解釈の重要語と文法など）も同じ窓で入れる。
9. 320×568と390×844で、主要操作、検索、ノート編集、単語帳編集、履歴確認に横スクロールや操作不能がない。

## 影響する入口・画面

- 主画面: `myList`（マイ学習ノート）
- 補助索引: `myLearning`
- 単語帳へ入れる: `vocabStudy` / `vocabQuiz` / `wordDetail` / `vocabSearch`、`phraseStudy` / `phraseQuiz`、`grammarQuiz`、`listeningQuiz`、`dictationPlay`、`etymologyStudy` / `etymologyQuiz`、古典単語・文法・常識の各暗記/テストと一覧、`kotenInterpretationPrep` / `kotenInterpretationQuiz`、`kanbunStudy` / `kanbunQuiz` / `kanbunCatalog`、`kanbunKundokuQuiz`、`literatureReader`。語源に紐づく単語の学習は専用画面ではなく `vocabStudy` を使う。
- 学習記録・復元確認: `progress`
- 共通入口: メニュー「マイ学習ノート」、単語画面と各コンテンツの「単語帳」

## 互換性契約

- 教材ID、既存SRS、辞書履歴、英作文の `myGrammarList`、進捗コード接頭辞、localStorageキーを変更しない。英単語の旧 `myList` と古典・漢文の旧登録リストは保存項目から外し、端末保存（版11への移行）・旧進捗コード・旧クラウド保存を読むときに単語帳へ移す。同じ保存を何度読んでも冊や項目は増やさず、登録が1つもなければ冊を作らない。
- 教材本文をノート状態へ複製せず、`domain:itemId` の安定参照だけを保存する。語源のようにID内にコロンがある場合も、最初のコロンだけを教材の区切りとして復元する。
- 新しい永続項目は `PERSISTED_PROGRESS_FIELDS` / `selectProgressState()` の一元契約を通す。
- 新項目を持たない旧端末データ・旧進捗コードは空の統合ノートとして読み込める。新項目を持たない古いクラウド保存で、現在端末の新しいノートを消さない。

## 完了判定

次をすべて満たした場合だけゴール完了とする。

- `npm run audit:notebook` が14教材・全15,957件、安定参照、保存形式、単語帳、学習経路、永続化経路をエラー0件で監査する。
- 統合ノートの対象テストが、旧リストの単語帳への移行、メモ・タグ上限、単語帳編集、SRS履歴、端末/コード/クラウド往復を通過する。
- `npm test`、`npm run check`、`npm run build`、`git diff --check`、`npm run check:deployment` が通過する。
- 実ブラウザで保存、再読込、新規タブ復元、単語帳作成/編集、各教材の学習起動、進捗反映を確認する。
- 390×844と320×568の両方で横方向の欠落がなく、コンソールエラーがない。
