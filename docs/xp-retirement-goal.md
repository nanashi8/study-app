# XP関連システム廃止ゴール

## ゴール

アプリ全体でXPを学習・報酬・成長の仕組みとして使用しない。正誤、SRS、復習期限、連続学習、分野別成績、診断、ノート、読了記録はXPから独立した既存の学習記録として維持する。

## 対象経路

1. 英単語、語源、熟語・構文、英文法、リスニング、ディクテーション、古典、英作文の回答・完了処理。
2. 各カード・クイズから学習結果画面へ渡すセッション情報。
3. 通常結果、龍脈結果、学習記録、進捗コード復元プレビュー、設定、メニュー。
4. 放課後分岐の報酬、記念品効果、スター交換、調査レベル、旧ゲーム画面の成長表示。
5. localStorage、`EQ1-`進捗コード、クラウド保存・復元、リセット、旧クイズ退避状態。

## XPを使用しない条件

- 正解、誤答、「わからない」、カード判定、作文完成、物語選択でXPを計算・加算しない。
- XPを画面に表示せず、レベル、解放、難易度、報酬、分析、推薦、演出の判断材料にしない。
- XPからスターへ交換する処理と操作を提供しない。
- 学習画面と結果画面の間でXP開始値・獲得値を受け渡さない。
- 物語報酬は絆、同行者、思い出、既存の解放記録だけを更新する。

## 保存互換性

- 旧保存データが持つ `stats.xp` と `battleXpSpent` は削除・別用途へ転用しない。
- 両値は `src/lib/legacyProgress.js` で非負整数へ正規化し、端末保存、進捗コード、クラウド同期で読み書きできる不活性な互換値としてだけ保持する。
- 新しい学習操作は旧値を増減させない。画面、要約、分析、分岐は旧値を読まない。
- 既存ID、SRS、履歴、保存リスト、設定、進捗コード接頭辞とlocalStorageキーを維持する。

## 完了判定

次をすべて満たした場合だけゴール完了とする。

- `npm run audit:xp-retirement` が全実行ソースを監査し、互換専用箇所以外のXP計算・受け渡し・表示・判断利用を0件と判定する。
- 回答5種、全SRS分野、英作文、放課後分岐を実行しても旧XP値が変化しないテストが通る。
- 旧端末状態、旧進捗コード、旧クラウド状態のXP値を安全に受け入れ、往復後も保持する互換テストが通る。
- `npm test`、`npm run check`、`npm run build`、`git diff --check`、`npm run check:deployment` が通る。
- 実ブラウザで主要学習結果、学習記録、設定、進捗復元プレビューにXP表示がなく、学習・復習・履歴が動作する。
- 390×844と320×568で横方向の欠落がなく、コンソールエラーがない。
