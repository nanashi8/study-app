# 語源資料を安全に参照する方針

## 目的

語源辞典・学習書は、既存データの見落としを発見するための調査資料として使う。収録するのは、複数の資料や既存語源メモで確認できる「語の由来・語根・意味変化」という事実だけとする。

## 収録してよいもの

- 語根の形、元の言語、基本義などの事実
- 同語源であることを確認できた、アプリ収録語どうしの関係
- 上の事実を、中高生向けにアプリ独自の順序と文章で説明したもの
- 書名・著者・出版社・刊行年など、参照履歴に必要な書誌情報

## 収録しないもの

- 本文、見出し、例文、語呂合わせのコピーまたは近い言い換え
- イラスト、図、色分け、ページ構成、章立て、項目の選択・配列
- PDF、ページ画像、OCR全文、索引全文
- 綴りが似ているだけの語や、資料間で由来が割れる語の断定的な同根リンク

## 追加手順

1. 資料からは「確認候補」だけを一時的に抽出する。
2. 全語彙と照合し、既存語源メモまたは独立した語源資料で関係を再確認する。
3. 同綴り・別語源を避けるため、補助語根リンクは見出し語の完全一致許可リストにし、既存の自動語根リンクも別語源の除外テストを通す。
4. 説明文は資料を閉じた状態で、事実から新しく書く。
5. `referenceRoots` は辞書の関連語表示だけに使い、既存の語源カードID、`etymologySrs`、進捗コード、クラウド同期を変えない。
6. 全語彙監査、誤接続テスト、変更前後のカード割当比較を通す。
7. 調査用PDF・画像・OCRはリポジトリへ入れず、作業後に破棄する。

## 法的な基準

文化庁は、単なる事実・データ・アイデア・ありふれた表現は著作物に当たらない一方、創作的な文章・図・素材の選択や配列は保護対象になり得ると説明している。本文等を引用する場合は、著作権法32条・48条に従い、必要性、明確な区分、正当な範囲、出所明示を個別に満たす。通常の語源データ追加では引用を行わない。
